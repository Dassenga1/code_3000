# Repository Security Statement

## Intended Users
This repository is intended for the use of myself and course instructor
so that my professor may review my assignments.

## Security Risks
This repository contains coursework and does not intentionally include
passwords, API keys, or private personal data. The security risk is low,
but unauthorized changes could affect the accuracy of my work, and
others could copy the code without permission.

## Security Measures
I avoid committing sensitive information and limit write access to
authorized collaborators. Because this is an individual coursework
repository with low security risk, a CODEOWNERS file and pull request
rulesets are not necessary at this time.
